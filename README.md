--- CAFE ORDER BUILDER ---

A responsive cafe takeaway order builder built with HTML, CSS, and Vanilla JavaScript.

Features:

- Display cafe menu items dynamically
- Search menu items by name
- Filter items by category
- Add items to the order
- Increase or decrease item quantity
- Remove items from the order
- Calculate the order total
- Customer name validation
- Order confirmation message
- Responsive design for desktop and mobile

Technologies Used:

- HTML5
- CSS3
- JavaScript
- JSON

Project Structure:

├── index.html
├── styles.css
├── script.js
├── data.json
└── README.md

How It Works:
The menu data is stored in "data.json".
JavaScript loads the menu data and dynamically renders the menu items on the page.
Users can search and filter the menu, add items to their order, adjust quantities, and confirm the order.

How to Run:
Open "index.html" in a browser.
For the best experience, run the project using a local development server such as VS Code Live Server.
